# RUNKHU

경희대 국제캠퍼스 주변에서 오늘 시간·컨디션·날씨를 말로 입력하면 실제 길 위에 러닝 코스 3개를 만들어 비교해 주고, 달리는 동안 길안내·음성 코칭, 달린 뒤 리포트까지 이어 주는 러닝 지도입니다. 2026 KHU AI Challenge(AI 문제해결 솔루션 부문) 출품작, 팀 orca.

## 서비스 URL

**https://orca-khu.vercel.app**

휴대폰 브라우저에서 바로 열 수 있습니다.

## 안드로이드 앱 (APK)

[RUNKHU.apk](RUNKHU.apk) → 파일 화면에서 **Download raw file** 버튼으로 받아 설치합니다.

- 설치할 때 "출처를 알 수 없는 앱" 허용이 필요합니다.
- 앱은 위 서비스 URL을 띄우므로 웹이 바뀌면 앱도 바로 최신입니다.
- 웹과 달리 화면이 꺼져도 위치 기록과 음성 안내가 이어지고, 잠금화면에 실시간 기록 알림이 뜹니다.
