## 단계별 활용

### 문제 정의
- **AI 모델:** Claude (외부) [ChatKHU 채팅을 썼다면 함께 기재]
- **주요 프롬프트:** "AI 활용 경진대회 공모 부문과 주제를 심사위원 관점에서 추천해 줘" → 후보 수십 개 중 팀이 "러닝 코스 지도"를 골랐습니다(거지맵처럼 지도 + 생활 밀착).
- **사람의 판단:** 흔한 학식·셔틀 챗봇은 차별성이 낮아 제외했습니다. 기존 앱과의 차이를 "기록이 아니라 어디를 달릴지 정해주는 앱"으로 정리했습니다.

### 자료 준비
- **AI 모델:** Claude Code (외부: 데이터 수집 스크립트 작성)
- **내용:**
  - OpenStreetMap에서 국제캠 주변 보행 도로망(노드 14,791개)과 신호등 교차로 62곳을 받았습니다.
  - SRTM 30m 고도를 약 100m 격자로 받아 노드마다 보간했습니다.
  - 스크립트는 `tools/graph.py`, `tools/signals.py`로 저장해 두어 다시 만들 수 있습니다.
- **사람의 판단:**
  - 국토지리정보원 공개DEM(5m)은 "국외 반출 금지" 조건이 있어 원본을 외부 서버나 AI에 올리지 않기로 정했습니다.
  - 카카오·네이버 지도 API는 고도를 주지 않는다는 점을 확인하고 고도 자료를 따로 구했습니다.

### 기획·설계
- **AI 모델:** Claude (외부, 설계 검토) / ChatKHU (프롬프트 실행)
- **핵심 설계:** "경로·경사는 알고리즘, 말·설명·판단은 AI."
  - AI가 좌표를 직접 그리면 실제로 없는 길이 나올 수 있어서, 처음부터 AI에게 경로를 그리게 하지 않았습니다.
- **ChatKHU에 준 규칙(시스템 프롬프트 발췌)**
  - 조건 번역: 사용자의 말을 `{start, place, here, km, minutes, terrain, night, novel, repeat_last}` JSON 하나로만 바꾼다. 말하지 않은 값은 null.
  - 브리핑: 주어진 코스 수치만 근거로 쓰고, 수치에 없는 시설·경치·안전 정보는 지어내지 않는다.
  - 코스 고치기: 후보 목록에 없는 id는 절대 쓰지 않는다.

### 제작·개발
- **AI 모델:** ChatKHU (서비스 기능) / Claude Code (외부, 코드 작성)
- **ChatKHU 연동 구조:** 브라우저 → `/api/ai`(Vercel 서버 함수) → ChatKHU 게이트웨이
  - 정해진 다섯 작업(parse·brief·refine·coach·report)만 받아서, 남이 키를 쓰는 공개 통로가 되지 않게 했습니다.
  - ChatKHU가 응답하지 않으면 규칙 기반 결과가 대신 보이도록 만들었습니다.
- **알고리즘:**
  - 순환 코스 생성: 출발점 기준 두 경유점, 최단경로 3구간, 이미 지난 길은 4배 비용으로 왕복 회피(`loop.js`)
  - 신호·오르막 반영 예상 시간
  - 방향별 경사
  - 자동 일시정지(8초 정지)
  - 지난 코스와의 겹침 계산(50m 칸)

### 테스트·개선 (실제로 겪은 문제와 수정)

| # | AI가 처음 한 것 | 사람이 판단해 바꾼 것 | 증빙 |
|---|---|---|---|
| 1 | 브리핑에서 최대 경사 9%를 "무리 없이 달릴 수 있어요"라고 씀 | 앱과 같은 경사 기준(8% 이상 급경사)을 규칙으로 넣고 "쉽다고 말하지 말 것"을 명시 | [전후 캡처] |
| 2 | "입니다요", "예요요" 같은 어색한 끝맺음 | 끝맺음 규칙("~예요/~해요/~세요" 한 번만) 추가 | [전후 캡처] |
| 3 | 코스 고치기 설명에 내부 변수 이름(`last_km_ascent`)이 그대로 노출 | 필드 이름 대신 "마지막 1km 오르막 20m"처럼 우리말로 쓰도록 규칙 추가 | [전후 캡처] |
| 4 | 러닝 리포트가 주어지지 않은 "목표 페이스"를 지어냄 | "목표 페이스는 주어지지 않으니 만들지 말 것" 추가 | [전후 캡처] |
| 5 | "새 코스" 추천이 평지를 보던 사람에게 산길을 고름 | 같은 지형 안에서 먼저 고르고, 모두 50% 넘게 겹칠 때만 다른 지형으로 넓히도록 변경 | [전후 캡처] |
| 6 | 장소 검색이 없는 지점명("스타벅스 영통역점")을 엉뚱한 지점(망포역점)으로 연결 | 이름이 정확히 맞지 않으면 후보 4곳을 보여주고 사용자가 고르게 변경 | [전후 캡처] |
| 7 | (알고리즘) 경사를 절댓값으로 칠해 내리막도 급경사(빨강)로 표시 | 팀원 제안으로 뛰는 방향 기준 오르막/내리막 구분 + "반대 방향으로 돌기" 추가 | [전후 캡처] |
| 8 | (알고리즘) 예상 시간이 거리×페이스뿐 | OSM 신호 교차로 수와 오르막 보정 반영, 자동 일시정지로 신호 대기 제외 | [전후 캡처] |

### 최종 결과물
- **AI 모델:** ChatKHU (서비스 내 5개 기능)
- **결과:** https://orca-khu.vercel.app — 말로 코스 주문 → 순환 코스 3개 → 대화로 수정 → GPS 길안내와 음성 코칭 → 리포트와 새 코스 추천
